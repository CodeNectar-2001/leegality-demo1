ShopEasy — Product Listing App

A simple online shopping website where you can see products, filter them, and view product details. Built using React.

Technologies used----
React – to build the website
React Router – to move between pages (Listing page and Detail page)
Vite – to run the project on your computer
CSS – for styling (colors, layout, etc.)
DummyJSON API – free public API used to get product data (https://dummyjson.com)

How to run this project-----------
Step 1: Install Node.js
Download and install it from nodejs.org (if not already installed).

Step 2: Open the project folder
cd leegality-demo1

Step 3: Install all required packages
npm install

Step 4: Start the project
npm run dev

Step 5: Open in browser
http://localhost:5173
